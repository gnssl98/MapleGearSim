# 인터뷰 기록

> 일시: 2026-10-15 · 리서치(`docs/research/`)를 바탕으로 결정 사항을 확정함

## 1차: 데이터 소스와 환경

| 질문 | 결정 | 비고 |
|---|---|---|
| 시세 데이터 입력 방식 | **수동 입력, 입력할 때마다 CSV에 누적 저장** | 공식 경매장 API가 없고, 웹 경매장 자동화는 약관 위반 소지가 있음 |
| 플레이 월드 | **일반 월드** | 통합 경매장. 타월드 매물은 구매가의 10%를 메이플포인트로 추가 지불 |
| 캐릭터 정보 | **넥슨 오픈 API 자동 연동** (수동 수정도 가능) | 개발 키는 5회/초, 1,000회/일. 캐시를 쓰면 개인용으로 충분 |
| 기술 스택 | **추천안 채택** | Python(FastAPI) + React(Vite, TS), Windows용 bat 실행 |

> 참고: 사용자가 "API 횟수 제한이 걸려 있을 것"이라고 우려함 → 오픈 API는 일 1,000회라 캐릭터 1회 조회(약 10~15콜)와 캐시로 충분하다고 답함. 웹 경매장의 일 100회 검색 제한은 수동 입력 방식이라 영향 없음.

## 2차: 계산 방식과 기능 범위

| 질문 | 결정 |
|---|---|
| 환산 주스탯 계산 | **단계적**: 1단계는 환산표(사용자가 수정 가능), 2단계는 내 스펙 기준 데미지 공식의 차이 |
| 아이템 범위 | **스타포스 가능 장비 전체** + 세트 효과 |
| 직작 분석 출력 | **기댓값 + 중앙값/백분위, 손익분기 가격, 비용 분포 차트, 혼합 전략 비교** (전부) |
| 추천 방식 | **억당 환산 효율 랭킹 + 예산 기반 최적 조합** (둘 다) |

## 3차: 비용 계산 세부

| 질문 | 결정 |
|---|---|
| 기존 장비 되팔기 | **반영**: 실질 비용 = 비용 − 기존템 시세 × (1 − 수수료). 가위 횟수가 0이면 판매 불가 처리 |
| 할인과 이벤트 | **MVP/PC방은 프로필 설정값**, 이벤트(30% 할인 / 파괴 −30% / 샤타포스)는 켜고 끌 수 있게 하고 "이벤트까지 기다리면 얼마나 아끼는지" 비교 |
| 원화 표시 | **메소와 원 병기**. 메소마켓 시세는 직접 입력. 메이플포인트 수수료 환산에도 사용 |
| 잠재 목표 | **프리셋 + 직접 지정** (예: 주스탯 30%+, 크뎀 2줄, 공 3줄, 주스탯% 합 ≥ N) |

## 4차: 데이터 단위와 우선순위

| 질문 | 결정 |
|---|---|
| 시세 기록 단위 | **매물 단위로 상세하게**: 아이템, 성, 잠재(등급과 옵션), 에디, 추옵 급수, 가격, 자서버/타서버, 날짜 |
| 캐릭터 수 | **본캐 1개 우선**. 데이터 구조는 다중 캐릭터로 확장할 수 있게 |
| MVP 우선순위 | **직작 계산기 먼저** → 캐릭터 연동 / 환산 / 추천 |

# 06. 장비 성장 생태계 (2025–2026 KMS) 리서치

> 작성일: 2026-10-15 / 대상: KMS
> 표기: **[확인]** 출처 직접 확인, **[커뮤니티]** 커뮤니티 의견, **[미검증]** 이번 조사에서 1차 출처 미확인

---

## 1. 개요

- 장비 성장은 "세트 조합 → 스타포스 → 잠재/에디셔널 → 추가옵션(추옵)"의 다축 업그레이드이며, 커뮤니티는 단계를 **환산 주스탯 구간(예: 4만, 7만, 10만, 13만+)** 으로 부른다. [확인: 나무위키 아이템 세팅, 2026-10-10 수정, 2026년 2월 경 기준 수치]
- 2026-09 기준 환산 최상위는 약 **15만** 수준. [확인: 동 문서]
- 신규/중간 유저 기본 전략은 **완제품 구매**가 합리적이라는 의견이 지배적이며, 15성 이상 직작은 파괴 위험 때문에 비권장. [확인: 동 문서]
- 리부트 월드는 2024년 단계적 "일반 월드화"를 거쳐 **에오스/핼리오스**로 개명, 거래·옥션·메소마켓이 열렸다(두 월드 한 그룹). [확인: 나무위키 일반 월드화 업데이트]
- 스타포스 최대치가 **2025-03-20 30성으로 확장**됨. [확인: 동 문서]

## 2. 상세

### 2.1 주요 장비 세트 / 부위 (2025–2026)

| 구분 | 세트/아이템 | 비고 |
|---|---|---|
| 방어구/무기 (160) | **앱솔랩스** | 초반·버닝 대체, 일부 무기 선택지 |
| 방어구/무기 (200) | **아케인셰이드** | 해방 전 무기·방어구 표준 |
| 방어구 (150 루타비스) | **루타비스**(모자/상의/하의 등 카오스 보스 드랍) | "3카5아" 의 '카' |
| 방어구 (250) | **에테르넬** | 상위 방어구, 18~22성+ |
| 무기 | 아케인 → **제네시스**(해방) → **데스티니**(2차 해방) | [확인] |
| 보조무기 | 기본 → **아스트라**(약 11만 구간) | [확인] |
| 엠블렘 | **미트라** | 완제품 구매 권장 |
| 장신구 | **보스 장신구 세트**(파풀마, 블빈마, 골클, 도미네이터 등), **여명의 보스 세트**(가디언 엔젤 링, 트와일라이트 마크, 에스텔라 이어링, 데이브레이크 펜던트), **칠흑의 보스 세트**(루컨마, 마깃안, 몽벨, 고근, 커포, 마도서, 창세 뱃지, 거공 등) | [확인: 나무위키 아이템 세팅 / 일부 명칭 일반지식] |
| 최상위 | **광휘** 세트 | 매우 고가, 13만+ 구간에서 4~5광휘 언급 [확인] |
| 기타 | 시드링, 가엔링, 마이링(마이스터링), 칠요/유산 훈장, 하트 등 | |
| 버닝/신규 | **도전자의 장비** + 제네시스 무기 (아이템 버닝 기본) | [확인] |

### 2.2 대표 세트 조합(무기·방어구) [확인: 나무위키]

- 해방 전: **3카5아**, **3에5아**
- 해방 후: 4카5앱, 4카5아, **4에5아(일반적 기본)**, 5에4아, 8에테 18~21성, 8에테 22성+ (현 최상위)

### 2.3 진행 순서와 환산 구간별 목표 [확인: 나무위키, 2026년 기준·참고용]

| 환산 구간 | 특징 | 예시 목표 |
|---|---|---|
| ~4–5만 | 유니크급 세팅(현재 저예산 기본) | 제네시스, 무기 윗잠 레전 2.5줄 |
| ~6만 | 레어 세팅("반레전둘둘") | 유니온 8,500, 본캐 285, 아티팩트 40 |
| ~7–8만 | 22성 레어~레전 | 유니온 9,000+, 칠흑 4세트(5~7 권장) |
| ~9만 | 데스티니 해방 직전 | Lv 295 |
| ~10–11만 | 가성비 칠흑 에테 | 칠흑 22성, 합잠재 43%+, 유니온 9,500+ |
| ~12만 | 고성능 칠흑 에테 | 헥사 스탯 주스탯 8+ |
| 13만+ | 엔드스펙 | 광휘 4–5, 고성 스타포스 |

- 스타포스 목표 [확인]: 저예산 17–18성 / 중예산 250제 18–19성, 그 외 21–22성 / 고예산 250제도 21성+. 30성 확장 이후 23성+ 비중은 [미검증].
- 잠재 목표: 주스탯% 기준 21성 레전·에디 유니크로 "총 주스탯 40%" 수준(22레에~레유 구간 권장) [확인: 검색 요약 나무위키], 장갑 크뎀·모자 쿨감 선호. 일반적으로 "레전 3줄 주스탯 30%+ (윗잠 33% 등)"이 상위 목표 [커뮤니티/미검증].
- 장신구 선택: **18성 칠흑 ≈ 22성 여명/보장** 성능, 22성은 비용 편차가 큼. 4~5칠흑 효율 좋음. [커뮤니티: 인벤 46656, 36179]
- 아케인 vs 에테르넬: 당장은 22성 아케인 > 18성 에테르넬일 수 있으나 장기적으로 에테르넬 우위. [커뮤니티: vortexgaming 1202634, 고과금 기준]

### 2.4 구매 vs 제작 [확인: 나무위키 아이템 세팅]

- **구매 권장**: 무기(아케인 직작 비추천), 미트라 엠블렘, 칠흑 아이템(가격대별 등급), 저가횟 아이템은 재판매가 하락 주의.
- **제작/직작**: 모자·상의·하의·장갑·신발·망토·벨트는 제작으로 에픽/유니크 잠재 얻기 쉬움, 귀걸이는 장신구 제작. 반지·눈장식·어깨는 제작 불가 → 큐브 필요.
- 초반: 6%/3% 에픽 장비 구매 후 상위 장비로 잠재 전승(토드).
- 환생의 불꽃은 거래 가능 템에 쓰면 가위 소모 등으로 재판매가 하락.
- 기대값보다 **중앙값** 기준으로 비용 계획.

### 2.5 일반 월드 vs 에오스/핼리오스(구 리부트) [확인: 나무위키 일반 월드화]

| 시점 | 변경 |
|---|---|
| 2024-08-13 (1차) | 보스 장비 조각 → 메소 교환, 같은 월드 큐브 이동 |
| 2024-09-12 (2차) | **캐릭터 간 거래·메이플 옥션·메소마켓 오픈**, 드랍 방식 일반 월드화, 레드/블랙 큐브 삭제, 기존 장비에 **귀속의 표식**(거래 불가, 메소마켓 판매가 1메소) |
| 2024-12-19 (3차) | 리부트 최종뎀 패시브 제거, **리부트→에오스, 리부트2→핼리오스** 개명, 챌린저스 리프, 옥션/메소마켓/보스매칭이 에오스·핼리오스 **한 그룹으로 통합** |
| 2025-03-20 | 스타포스 30성 확장(귀속의 표식 템 제외) |
| 2025-09-18 | 플라즈마 하트 업그레이드(귀속 템 제외) |
| 2026-06-18 | 챌린저스 시즌4 에오스/핼리오스 전용 서버 운영 |

- 프로그램 관점: 에오스/핼리오스는 **일반 월드와 거래 규칙이 거의 동일**하나 **시장(옥션·메소마켓)은 별도 그룹** → 시세 데이터는 월드 그룹별로 분리 필요. 귀속의 표식 템은 거래·일부 강화 불가.
- 테스트월드(2024-12) 공지에는 옥션/메소마켓 월드 통합 구조(타 월드 구매 시 메이플포인트 10% 수수료)가 소개됨 — 일반 월드 간 통합 현황은 [미검증].

### 2.6 메소 가치 컨텍스트

- 단위: 커뮤니티 시세는 **억 메소** 단위(예: "100억", "1조"). 장비 가격·강화 비용 모두 억 단위로 표기.
- 원/억 시세 [확인, 단 오래됨]: 2023-08 기준 **1억 ≈ 2,100~2,400원**(서버마다 다름), 이후 "2,000~3,000원대 회복" 언급(날짜 미상). 2025-07 커뮤니티 글에 "100억 ≈ 25만원(1억 ≈ 2,500원)" 언급(메소마켓이 아닌 장외 거래 시세라는 반론 있음).
- 메소마켓: 메이플포인트 ↔ 메소 교환, 유저 간 거래 수수료(3~5%) 없음, 1회 1,000억 한도·일 100회 [확인: 나무위키 메소, 최신성 미검증].
- **2026년 현재 시세는 확인하지 못함** → 사용자가 직접 입력하도록 설계 권장.

## 3. 프로그램 설계 시 시사점

1. **장비 카탈로그 데이터 모델**: 세트(앱솔/아케인/루타/에테르넬/보장/여명/칠흑/광휘), 부위, 레벨, 세트효과 단계별 옵션을 정적 데이터로 관리하고 패치 버전 태그.
2. **업그레이드 후보 유형**: (a) 아이템 교체(구매), (b) 스타포스 n→m, (c) 잠재/에디 재설정(큐브), (d) 추옵(환불/환생), (e) 세트 조합 변경(세트 효과 증감 포함). 각 후보에 Δ환산(05 문서) / 비용(억) = **억당 환산**.
3. **세트 효과의 비선형성**: 한 부위 교체가 두 세트의 단계 변화를 유발 → 부위 단독 비교가 아니라 전체 세팅 재계산 필요.
4. **비용 모델**: 스타포스·큐브는 확률 분포(중앙값·P75·P90), 구매는 시세 + 수수료, 재판매가(가위 횟수) 반영 순비용.
5. **월드 구분**: 일반 월드 / 에오스·핼리오스 그룹 / 챌린저스를 사용자 설정으로 두고 시세·거래 가능 여부·귀속 템 처리 분기.
6. **원화 환산은 옵션**: 원/억 시세를 사용자 입력값으로 받아 "원당 환산"도 표시 가능(시세 자동 수집은 출처 불안정).
7. **목표 프리셋**: 환산 구간별 대표 세팅(위 2.3 표)을 "다음 단계 목표" 추천 프리셋으로 활용하되 커뮤니티 기준임을 명시.

## 4. 불확실 / 추가확인 필요 항목

- [ ] 30성 확장 이후 실제 상위권 스타포스 목표(23~25성) 및 비용 테이블 최신값(스타포스 확률/비용 공식 공지).
- [ ] 광휘 세트 구성·세트효과 수치, 칠흑/여명 세트효과 최신 수치.
- [ ] 2026년 현재 메소 시세(원/억), 일반 월드 vs 에오스·핼리오스 시세 차이.
- [ ] 일반 월드 간 옥션/메소마켓 통합 여부 및 수수료 규정(현행).
- [ ] 큐브 확률(넥슨 Open API "확률 정보 조회"로 확보 가능 여부) 및 잠재 옵션 등급별 수치.
- [ ] 2.1 표의 일부 아이템 명칭/세트 소속은 일반 지식 기반 → 데이터 구축 시 공식/위키 대조 필요.

# 05. 환산 주스탯 (Stat-equivalent Main Stat) 리서치

> 작성일: 2026-10-15 / 대상: KMS(한국 메이플스토리)
> 표기: **[확인]** = 출처에서 직접 확인, **[커뮤니티]** = 커뮤니티 글 기준(버전/스펙 의존), **[미검증]** = 일반 통용 지식이나 이번 조사에서 1차 출처로 확인하지 못함

---

## 1. 개요

- **환산 주스탯**은 넥슨 공식 지표가 아니라 유저들이 만든 **"전체 딜 기대값을 주스탯 단위로 환산한 단일 숫자"** 이다. 공격력·스탯%·데미지·보공·크뎀·방무 등 곱연산 요소를 모두 "주스탯 몇 포인트에 해당하는가"로 바꿔 하나의 스칼라로 표현한다. [확인: 나무위키 환산 주스탯, 인벤 34689]
- 기원 [확인: 나무위키]
  - 2021년 말 **엑셀 시트**(수기 입력) 형태로 최초 배포.
  - 2023년 6차 전직 업데이트 이후, 엘리시움 서버 유저(고마오)가 **넥슨 Open API 기반 웹사이트**로 구현 → 현재 **https://maplescouter.com/** ("환산주스탯", Maple Scouter). 이후 운영진 합류.
  - 사이트 하단: "Data Based on NEXON OPEN API", "MAPLESTORY PARTNERS", 넥슨과 무관. [확인: maplescouter.com]
- 용도: 보스 컷(파티 모집 기준), 캐릭터 강함 비교, 랭킹(헥사 환산 랭킹), 장비 부위 효율 비교. 커뮤니티에서는 "환산 4만/7만/10만" 처럼 **스펙 단계 표기 단위**로 쓰인다. [확인: 나무위키 아이템 세팅]
- 인게임 **전투력**(공식 지표)과의 차이: 환산은 항상 *보스 세팅 기준*으로 기록, 전투력은 드메템 착용 시 수치가 흔들림. 환산 2만 미만에서는 정확도가 낮고 2만~4만은 과도기. [확인: 나무위키 환산 주스탯]

## 2. 상세

### 2.1 데미지 공식의 기본 구조 [커뮤니티]

인벤 가이드(2023-07-05, "검마를 잡아보자 1")가 정리한 곱연산 체인:

```
데미지 = [(주스탯×4 + 부스탯) × 총공격력 × 무기상수 × 직업보정상수 / 100]   ← 스탯공격력(인게임 표기)
       × (스킬 퍼뎀 / 100)
       × 크리티컬 발동 시 크리티컬 데미지 보정
       × (100 + 공격력%) / 100
       × (100 + 데미지% + 보공%) / 100        ← 데미지%와 보공%는 '합연산'
       × 방어율 무시 보정
       × 렙차 보정 × 속성 보정 × 포스(아케인/어센틱) 보정 × 숙련도 보정
       × (100 + 최종데미지%) / 100            ← 최종뎀은 서로 곱연산
```

세부 항(인벤 22224, 2020) [커뮤니티]:
- 주스탯 항: `4×(순주스탯×(1+주스탯%) + 미적용주스탯) + (순부스탯×(1+부스탯%) + 미적용부스탯)`
  - **미적용 스탯**(심볼, 하이퍼스탯, 어빌 레벨비례 등 %의 영향을 받지 않는 고정 스탯)은 %와 곱해지지 않음.
- 공격력 항: `순공격력 × (1+공격력%) + 미적용공격력`
- 크리티컬 항: `(1.35 + 크뎀)` — 기본 크리 배율 1.20~1.50 랜덤의 평균 1.35 사용.
- 방무 항: `1 − 보스방어율 × (1 − 실방무)`, 실방무 = `1 − Π(1 − 방무_i)` (방무는 곱연산 누적)
- 반감(×0.5)/리셋(×1.1) 등 보스 기믹 보정이 추가될 수 있음.

> 주의: 위 공식은 2020~2023년 커뮤니티 정리이며, 이후 패치(크리티컬 공식, 숙련도, 포스 보정 등)로 세부가 바뀌었을 수 있다. 정확한 **무기상수/직업보정상수 표**는 이번 조사에서 1차 출처로 확보하지 못함. [미검증]

### 2.2 환산 원리: "한계 딜상승률 비율" [커뮤니티]

- **딜상승률** = 증가량 / 기존값 (해당 곱 항 기준)
- **x의 y 대비 효율** = (x 1단위의 딜상승률) / (y 1단위의 딜상승률) [인벤 22224]
- 환산 주스탯 = 현재 캐릭터의 모든 곱 항을 "주스탯 1포인트의 한계 딜상승률"로 나눠 주스탯 단위로 표현한 값.
- **따라서 환산 계수는 고정 상수가 아니라 현재 스펙의 함수이다.** 예:
  - 공격력 1의 가치 ∝ (스탯 환산치 / 총공격력) — 공격력이 높을수록 공격력 1의 가치가 떨어짐.
  - 보공 1%의 가치 ∝ 1 / (100 + 데미지% + 보공%) — 보공·데미지가 높을수록 감소.
  - 방무 1%의 가치는 보스 방어율과 현재 방무에 따라 비선형(적정방무 = 보공과 방무의 한계효율이 같아지는 지점, 직업/스펙별 상이). [인벤 34689]
  - 심볼 등 미적용 스탯 비중이 커질수록 스탯% 효율은 하락하고 공마 효율은 상승. [인벤 22224]

### 2.3 커뮤니티 경험칙(rule-of-thumb) 환산값 [커뮤니티, 스펙 의존]

| 옵션 | 주스탯 환산(대략) | 출처/시점 |
|---|---|---|
| 공격력/마력 1 | 주스탯 **≈ 3.5 ~ 4** | 인벤 34689(2023): 4 / 인벤 46656: 3.5 |
| 주스탯% 1% (=올스탯% 1%의 주스탯분) | 주스탯 **≈ 10** (일부 시트는 상위 스펙에서 12~13) | 인벤 34689 |
| 올스탯% 1% | 주스탯% 1% + 부스탯% 1% → 대략 주스탯 10 + (부스탯분 ≈ 1) | [미검증: 부스탯 기여는 ×1/4 수준] |
| 부스탯 1 | 주스탯 **≈ 0.1 ~ 0.25** | 인벤 46656: 0.1, 공식상 1/4(스탯%·미적용 비중 따라 축소) |
| 공격력% 1% | 주스탯 **≈ 40** (공격력 10 상당) | 인벤 34689 |
| 데미지% / 보공% 1% | 주스탯 **≈ 15** (글에 따라 14~15) | 인벤 34689, 46656 |
| 크리티컬 데미지 1% | 주스탯 **≈ 35 ~ 40** | 인벤 34689(35), 46656(40) |
| 방어율 무시 | 고정값 없음(보스 방어율·현재 방무 의존) | 인벤 34689 |
| 쿨타임 감소 | 직업·조작 의존, 일반화 불가 | 인벤 34689 |

예시(인벤 34689): 주스탯 299, 스탯% 29, 공격력 129 신발 → 299 + 290 + 129×4 = **1105 주스탯 환산**.
나무위키(아이템 세팅) 표현: "데미지 10% ≈ 주스탯 13%, 크뎀 5% ≈ 주스탯 20%" 수준.

> 이 표는 "단순 부위 비교용"이며, 실제 환산 사이트는 캐릭터 전체 스펙으로부터 매번 계산한다. 프로그램에서는 **고정 계수 대신 현재 스펙 기반 미분(혹은 차분)** 으로 계산해야 한다.

### 2.4 직업 예외 [일부 미검증]

| 직업군 | 차이점 | 상태 |
|---|---|---|
| 마법사 | 공격력 대신 **마력**, 주스탯 INT / 부스탯 LUK | [확인: 인벤 34689] |
| 도적 일부(섀도어·듀얼블레이드·카데나 등) | 부스탯이 STR+DEX 2종 | [미검증] |
| **제논** | STR·DEX·LUK 3종이 모두 주스탯 역할 (흔히 `4×(STR+DEX+LUK)` 형태로 정리됨, 부스탯 없음). 올스탯% 효율이 타 직업보다 높음 | [미검증 — 정확식 확인 필요] |
| **데몬어벤져** | 주스탯이 **HP**. 추가옵션은 HP+ 위주로 받음, HP 상한(50만 언급) 존재. 흔히 "순수 HP와 추가 HP를 다른 계수(÷3.5 등)로 환산 + STR(부스탯)" 형태로 알려짐 | [커뮤니티: 인벤 8612 등 / 정확식 미검증] |
| 궁수 | 크뎀 기본치가 높아 크뎀 효율 차이 | [확인: 인벤 34689] |
| 쿨감 의존 직업 | 쿨감 1초 가치가 직업별로 큼 | [확인: 인벤 34689] |

### 2.5 환산 효율 / 억당 환산 (메소 대비 효율)

- 개념: 업그레이드 후보 *i*에 대해 `효율_i = Δ환산_i / 비용_i(억 메소)` → "1억당 환산 X 상승". 높은 순으로 투자.
- 이번 조사에서 **억당 환산을 정식으로 정의한 1차 출처는 찾지 못함**. 다만 커뮤니티 질문글(인벤 44432, 2025-07: 스타포스 vs 엠블렘 잠재 vs 메획 투자 비교)처럼 **비용 대비 효율 비교 수요는 명확**하다.
- 비용 산정 시 유의(나무위키 아이템 세팅 [확인]):
  - 스타포스 15성 이상은 비용 분산이 매우 크므로 **기댓값보다 중앙값**이 더 실용적.
  - 거래 가능 장비는 재판매가(가위 횟수, 환불 추옵 여부 등)를 고려한 **순비용**으로 봐야 함.

## 3. 프로그램 설계 시 시사점

1. **고정 계수 테이블 대신 "스펙 함수"로 구현**: `power(spec)` 를 데미지 기대값 곱 형태로 구현하고, 환산 주스탯 = `power(spec)` 를 "주스탯 1 증가 시 power 증가분"으로 정규화. 아이템 교체/강화 효과는 `power(spec') − power(spec)` 를 같은 단위로 환산(차분 방식)하면 비선형(방무·보공 포화)이 자동 반영됨.
2. **기준치 기반 '전체 스탯 역산' 필요**: `character/stat` 은 최종값만 주므로, 장비 하나를 바꿨을 때 효과를 계산하려면 장비·세트·하이퍼·유니온·심볼 등에서 **순스탯/스탯%/미적용 스탯을 분리**해야 함. 1차 버전은 "최종 스탯 + 장비 변경분 차분"으로 근사하고, 근사 오차를 문서화.
3. **환산 계산 버전 관리**: 공식·상수(무기상수, 보스 방어율, 크리 배율 등)를 설정 파일로 분리하고 버전 태그. 패치 시 갱신.
4. **기준 보스 파라미터화**: 방무 가치가 보스 방어율에 크게 의존 → 대상 보스(예: 방어율 300%/380%) 선택 옵션.
5. **직업 플러그인**: 일반/마법사/제논/데몬어벤져/부스탯 2종 직업을 전략 패턴으로 분리.
6. **억당 환산 = Δ환산 / 순비용**: 순비용 = 구매가 − 예상 재판매가(또는 강화 비용 *중앙값*). 스타포스·큐브는 분포(중앙값/분위수)를 같이 표시.
7. **외부 검증용 앵커**: maplescouter 값과 비교 테스트(수동)로 공식 보정. simaple 코드를 레퍼런스로 참고(라이선스 확인 후).
8. **API 사용 정책 준수**: 30일 갱신 의무, API 키 보관, 일일 스냅샷 기반이므로 "실시간 반영 아님"을 UI에 명시.

## 4. 불확실 / 추가확인 필요 항목

- [ ] maplescouter의 **정확한 계산식·가정**(기준 도핑, 크리 평균, 보스 방어율, 유니온 포함 여부) — 사이트 가이드/FAQ/업데이트 내역 본문 직접 확인 필요.
- [ ] **무기상수·직업보정상수** 최신 표 (나무위키 "데미지 공식" 문서 접근 실패).
- [ ] **제논·데몬어벤져** 스탯공격력 정확식 및 환산 방식.
- [ ] 2024~2026 패치로 바뀐 공식 요소(크리티컬 데미지 공식, 숙련도, 최종뎀 항, 헥사 스탯) 반영 여부.
- [ ] `character/stat` 의 정확한 필드명(전투력, 최대/최소 스탯공격력 등)과 데이터 제공 시작일·rate limit.
- [ ] simaple 최신 유지보수 여부, 라이선스, Open API 직결 가능 여부.
- [ ] "억당 환산"의 커뮤니티 표준 정의(재판매가 반영 여부 등) — 공식화된 출처 미발견.

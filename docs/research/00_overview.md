## 프로그램 설계에 결정적인 사실

1. **공식 경매장 API는 없다.** 오픈 API에 경매장 카테고리가 없고, 웹 경매장(auction.maplestory.nexon.com)은 200레벨+·OTP·일 100회 검색 제한이 있으며 자동화는 약관 위반 소지가 큼.
   → 시세는 **수동 입력/관리**가 기본안.
2. **캐릭터 장비·스탯은 오픈 API로 가져올 수 있다.** (`x-nxopen-api-key`, 개발 키 5회/초·1,000회/일)
   잠재옵션은 자유 텍스트이므로 파서가 필요하고, 숫자 대부분이 문자열로 옴. 필드명은 실제 응답으로 검증해야 함.
3. **환산 주스탯은 비공식 지표.** 환산(maplescouter)은 공식을 공개하지 않음.
   - 데미지 공식으로 직접 구현하고, "장착 후 − 현재"의 차이(한계효용)로 계산해야 정확함.
   - 공 1≈4, 스탯% 1≈10 같은 고정 환산표는 근사치일 뿐임.
4. **스타포스(2026-03-19 패치 기준)**
   - 스타캐치가 폐지되고 ×1.05 성공 보정이 상시 적용됨.
   - 일반 장비는 실패해도 하락이 없고, 최대 30성.
   - 파괴되면 직전 성(22성 상한)을 유지하며, 스페어 1~4개로 복구.
   - 비용 공식 `1000 + L³(S+1)^e/d`로 마르코프 체인 기댓값을 계산하면 커뮤니티 수치와 일치함(16.54억).
5. **잠재능력(메소 재설정)**
   - 등급업 확률과 천장이 있음.
   - 공식 확률 페이지의 내부 엔드포인트로 옵션별 확률표를 얻을 수 있고, 이걸로 목표옵션 달성 확률을 정확히 계산할 수 있음.
   - 추가옵션은 300만 메소 고정 재설정(검환불과 동일 확률).
6. **월드 그룹:** 일반 월드끼리는 통합 경매장, 에오스/핼리오스는 별도 그룹.

## 주요 미확인 항목 (구현 중 검증 필요)

- 스타포스: 23~29성 비용 계수, 복구 메소 공식, MVP/PC방 할인 적용 상한(16성 vs 17성)
- 잠재: 미라클 타임과 메소 재설정·천장의 상호작용
- 추옵: 무기 공격력 추옵 공식, 확률 모델의 가정
- API: 실제 필드명과 값 포맷
- 환산: 무기상수·직업보정 최신 테이블, 제논/데벤져 공식
- 메소 시세: 현재 원/억 시세(사용자 입력 권장)

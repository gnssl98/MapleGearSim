# 02. 경매장(메이플 옥션) 데이터 접근 & 시스템 규칙 조사

> 조사일: 2026-10-15 · 대상: 메이플스토리 한국(KMS)
> 표기: **[공식]** = maplestory.nexon.com / openapi.nexon.com, **[나무]** = 나무위키, **[커뮤]** = 인벤 등 유저 글.

## 1. 개요

- **공식 경매장 API는 존재하지 않는다** (2026-10-15 기준).
  - 넥슨 Open API 메이플스토리 카테고리: 캐릭터/유니온/길드/연무장/확률/스케줄러/랭킹/공지 — 경매장 없음 [공식].
  - 가장 최근 메이플 Open API 업데이트(2026-08-20)도 other-stat·연무장·스케줄러 관련뿐 [공식].
  - 2026-02-25 인벤 글 "경매장도 API 제공되면 참 좋을텐데" — 유저 측에서도 미제공 인식 [커뮤].
- 가격 데이터를 얻는 현실적 방법: ① **수동 입력**(인게임 옥션 '시세' 탭/검색 결과를 보고 입력), ② 비공식 시세 사이트 참고(수집 방식 불투명), ③ 공식 **웹 옥션**(로그인·OTP 필요, 자동화는 약관 리스크).
- 핵심 규칙: 판매 수수료 **5%**(MVP 실버 이상/프리미엄PC방 **3%**), **월드 통합 옥션**(2024-12-19~, 장비·캐시), 타 월드 매물 구매 시 **가격의 10% 상당 메이플포인트 추가 수수료**(구매자 부담), 거래 그룹 분리(일반 vs 에오스/핼리오스 등).

## 2. 상세

### 2.1 공식 API 부재와 대안

| 수단 | 내용 | 평가 |
|---|---|---|
| 넥슨 Open API | 경매장 엔드포인트 없음. 단, `item-equipment`로 **캐릭터가 착용한 장비**의 옵션은 조회 가능 | 가격 X, 장비 스펙 O |
| 인게임 옥션 시세 탭 | 특정 아이템 **최근 3개월 거래 금액·일자** 조회, 장비는 최대 500건 노출 [공식/나무] | 가장 신뢰도 높음, 수동 |
| 웹 옥션 (auction.maplestory.nexon.com) | 200레벨 이상 캐릭터, **넥슨 OTP 가입 계정만**, 검색 **일 100회**, 판매 등록 일 20회, 게임 접속 중 거래 불가, 수령은 인게임 [공식 가이드] | 자동 수집 대상으로 부적합(로그인·OTP·일일 제한, 약관) |
| 메이플 핸즈(모바일) | 2024-12 쇼케이스에서 "경매장 조회 및 구매" 기능 예고 [기사] | API 아님 |
| 비공식 시세 사이트 | 메이플리치(maplerich.kr): 옥션 시세 탭의 판매완료 기록 기반, 옵션별 가격 추정·에오스/핼리오스 지원(2025-03 리뉴얼 글) / 메이플증권(mitemprice.kr): "Nexon Open API 데이터 활용", "매일 업데이트되는 최저가 데이터" 표기 / maple-price-board.pages.dev: 과거 판매완료 기록 기능을 **현재 제거**(현재가로 오인 우려) / maple.ai.kr: 주요 물욕템 일별 시세(2026-01-01~) | 수집 방법 미공개, 공식 API 아님. 참고용 |

**스크래핑/자동화 리스크**
- 넥슨 Open API 약관: API 수집 데이터는 30일 내 갱신 의무 [공식].
- 웹 옥션은 로그인+OTP 뒤에 있음 → 자동화는 넥슨 이용약관(비인가 프로그램/비정상 이용 금지 류 조항) 위반 및 계정 제재 소지. 국내 법률 자료상 무단 크롤링은 기술적 보호조치 우회 시 부정경쟁방지법·정보통신망법·업무방해 문제 가능 [일반 법률 칼럼]. → **본 도구에서는 스크래핑하지 않는다**.
- 인게임 메모리/패킷 읽기: 명백한 약관 위반·제재 대상 → 배제.

### 2.2 경매장(메이플 옥션) 기본 규칙

| 항목 | 내용 | 출처 |

### 2.3 월드 통합 옥션 (타서버 매물)

- **도입**: 2024-12-07 겨울 쇼케이스에서 "11년 만에 경매장 월드 통합" 발표 → **2024-12-19 패치**로 **장비·캐시 아이템**에 한해 도입 (소비/기타는 월드별 유지로 기록) [기사, 나무].
- 타 월드 매물은 아이콘에 **[W]** 표시, '현재 월드 아이템만' 체크로 필터 가능. 타 월드 캐시 아이템은 일괄 구매 제한.
- **거래 그룹** (같은 그룹 안에서만 거래):
  - 공식 가이드(2026 시점 페이지): 그룹1 = 스카니아·베라·루나·제니스·크로아·유니온·엘리시움·이노시스·레드·오로라·아케인·노바 / 그룹2 = **에오스·핼리오스** / 그룹3 = 특수 월드(챌린저스 등).
  - 나무위키: **2026-06-18 패치**로 1그룹(일반 월드 + 챌린저스 1·2·3) / 2그룹(에오스·핼리오스 + 챌린저스 4)로 기재. → 공식 가이드와 챌린저스 분류가 **상충**, 챌린저스 시즌 운영에 따라 바뀌는 부분으로 보임.
  - 2024-12 발표 당시에는 일반/버닝/에오스/핼리오스 4그룹으로 보도됨(이후 버닝 월드 정책 변화로 현행과 다름).
- 에오스·핼리오스(구 리부트)는 일반 월드와 거래 불가, 메소마켓도 별도.

### 2.4 교환 가능 횟수 / 교환 불가 조건

- 대부분 장비는 드롭 시 **교환 가능 + "가위 사용 가능 횟수"**(일반적으로 10회, 아이템에 따라 20회 등 상이) 보유 [커뮤]. 일부 보스 보상은 횟수가 있어도 처음부터 교환 불가.
- **장착 시 교환 불가** 아이템: 착용하면 교환 불가 → **플래티넘 카르마의 가위**(캐시)·카르마의 가위 등으로 횟수 1 소모 → **1회 교환 가능** 상태로 변경 [커뮤].
- 옥션에서 **플래티넘 카르마의 가위를 사용한 장비를 구매하면 교환 불가 상태로 수령**(즉, 구매자는 착용 후 다시 팔려면 가위가 또 필요) [공식 가이드]. 2021-10-14부터 1회 교환 가능 아이템 구매 시 경고 표시 [나무].
- 캐시 아이템은 수령 시 교환 불가(일부 결과물 예외) [공식].
- API 필드 `cuttable_count`(가위 사용 가능 횟수)로 착용 장비의 재판매 가능성 판단 가능.
- 옥션 검색 옵션: "가위 사용 가능 횟수", "가위 사용 가능 횟수 미부여", "장착 시 교환 불가" [나무].
- **스타포스·잠재 재설정 자체로 교환 불가가 되는 일반 규칙은 확인되지 않음**(고강 장비가 옥션에 상시 거래됨). 다만 놀장강 적용, 특정 이벤트/카르마 재화(예: 챌린저스 상점의 카르마 큐브·카르마 스타포스 강화권, 카르마 에디셔널 주문서 등)는 해당 아이템/월드 제한이 있음 → **확인 필요**.

### 2.5 메소 시세 / 메소마켓

- **메소마켓**: 메소 ↔ 메이플포인트(MP) 경쟁매매 거래소. 거래 단위 1억 메소, 1회 최대 1,000억, 일 100회 등록. **메소 판매 시 받는 MP의 1% 수수료**, 메소 구매 수수료 없음. 호가창 없이 평균 거래가·시장가·최우선 입찰가 제공 [나무].
- 에오스·핼리오스 제외 월드 메소마켓 통합(챌린저스 포함) [나무].
- 메이플포인트는 넥슨캐시로 충전(대략 1 MP ≈ 1원 가치로 통용되나 충전 보너스 등 상이) → **메소→원화 환산 = 메소마켓 1억당 MP 시세** 로 근사.
- **현재(2026-10) 1억 메소당 MP 시세는 신뢰할 출처를 찾지 못함** → 수치 미기재. 변동이 크므로 사용자가 입력하도록 설계.
- 타 월드 구매 수수료(10%)의 MP 환산도 이 메소마켓 시세(매일 10시 갱신)를 따름.

## 3. 프로그램 설계 시 시사점

1. **가격 입력은 수동이 기본**: 아이템별 "가격(메소) + 기준일 + 출처(시세탭/매물/사이트) + 월드 그룹" 레코드를 저장. 오래된 가격은 경고(예: 14일 경과).
2. **실구매비용 계산식**:
   - 같은 월드: `구매비용 = 가격`
   - 타 월드: `구매비용 = 가격 + max(10 MP, floor(가격 × 0.10 × MP/메소 환율))` (MP를 메소로 다시 환산해 총비용 비교)
   - 판매 회수액: `가격 × (1 − 0.05 또는 0.03)` (MVP 실버 이상/프리미엄PC방 설정값)
3. **업그레이드 효율** = (스탯 환산 증가량) ÷ (순비용 = 구매비용 − 기존 장비 판매 회수액(가능 시)).
4. **재판매 가능성 체크**: 현재 장비의 `cuttable_count`·교환 상태를 표시 → 0회/교환불가면 회수액 0 처리. 구매 대상이 "플카 사용 장비"면 재판매 시 가위 비용(캐시) 추가.
5. **월드 그룹 설정**: 사용자 월드 → 그룹 자동 매핑(일반 / 에오스·핼리오스 / 챌린저스), 그룹 매핑은 설정 파일로 분리(패치로 변동).
6. **메소↔원화**: 사용자 입력 `1억 메소 = N MP(≈원)`; 결과를 메소와 원화 병기.
7. 스크래핑·웹옥션 자동화 미구현(약관). 향후 넥슨이 경매장 API를 추가하면 가격 소스를 플러그인으로 교체할 수 있게 인터페이스 분리.
8. 수수료율·그룹·최소 수수료 등은 **상수 하드코딩 금지**, 설정값으로.

## 4. 불확실 / 추가 확인 필요

- 경매장 API: 2026-10-15 기준 없음으로 판단하나, 공식 공지 목록 전체를 확인하지 못함(페이지 JS 렌더링). 주기적 재확인 필요.
- 챌린저스 월드의 옥션 그룹 소속(공식 가이드 '그룹3 특수월드' vs 나무위키 2026-06-18 '1/2그룹 분할') 상충.
- MVP 개편 공지의 정확한 일자(검색상 2025-04-17) 및 이후 변경 여부.
- 플래티넘 카르마의 가위 현재 가격, 아이템별 기본 가위 횟수, 놀장강/카르마 재화 사용 시 교환 제한 상세.
- 현재 메소마켓 시세(1억당 MP) — 수치 확보 실패.
- 비공식 사이트(메이플증권 등)의 가격 수집 방식 및 이용약관 적합성 불명.
- 소비/기타 아이템의 월드 통합 여부가 이후 패치로 바뀌었는지 미확인.

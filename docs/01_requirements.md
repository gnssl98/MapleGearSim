## 1. 목적

장비를 맞출 때 **"무엇을, 사야 할지 직접 만들어야 할지(직작)"**를 메소 기준으로 판단하게 돕는 개인용 로컬 웹 도구.

1. **직작 계산기**: 스타포스, 잠재, 에디셔널, 추가옵션 단계별로 비용의 기댓값과 분포, 손익분기 시세를 계산한다.
2. **업그레이드 시뮬레이터**: 내 캐릭터의 현재 장비를 기준으로, 구매나 직작 후보들의 환산 증가량 대비 실질 비용(억당 환산)을 비교하고, 예산 안에서 최적 조합을 추천한다.

## 2. 범위

### 포함
- 일반 월드 기준 거래 규칙(통합 경매장, 타월드 구매 시 메이플포인트 10%)
- 스타포스가 가능한 모든 장비 + 세트 효과
- 본캐 1명(다중 캐릭터 확장을 고려한 구조)
- Windows 로컬 실행, 브라우저 UI

### 제외 (현재 버전)
- 경매장 데이터 자동 수집(공식 API가 없고 약관 위반 소지가 있음)
- 에오스/핼리오스 월드, 다중 캐릭터 UI
- 캐시 아이템, 심볼, 헥사, 유니온 육성 시뮬레이션(환산 계산의 입력값으로만 사용)
- 외부 배포, 로그인, 서버 호스팅

## 3. 사용자와 실행 환경

- 사용자: 본인 1명(메이플 숙련자)
- OS: Windows 10/11 (개발은 macOS에서도 가능)
- 실행: `start.bat`을 더블클릭하면 로컬 서버가 뜨고 브라우저가 열림(`http://localhost:포트`)
- 네트워크: 넥슨 오픈 API를 호출할 때만 필요. 나머지는 오프라인으로 동작

## 4. 기능 요구사항

> 우선순위: **P1** = MVP(1차 출시), **P2** = 2차, **P3** = 이후

### 4.1 공통 설정 (F-SET)

| ID | 요구사항 | 우선 |
|---|---|---|
| F-SET-01 | 프로필 설정: MVP 등급(없음/브론즈/실버/골드/다이아/레드), 프리미엄 PC방 여부 | P1 |
| F-SET-02 | 이벤트 토글: 스타포스 30% 할인, 파괴 확률 −30%, 5/10/15성 100%, 샤이닝 스타포스(조합), 미라클 타임 | P1 |
| F-SET-03 | 메소마켓 시세(원/1억 메소) 입력. 메소와 원을 함께 표시 | P1 |
| F-SET-04 | 넥슨 오픈 API 키 입력과 저장(로컬 `.env`/설정 파일, 외부 전송 금지) | P2 |
| F-SET-05 | 게임 수치 테이블(확률·비용·옵션)을 데이터 파일로 분리하고 버전을 표기. 패치가 오면 파일만 고쳐서 반영 | P1 |

### 4.2 직작 계산기 (F-CRAFT) — **MVP 핵심**

#### 4.2.1 스타포스 (F-SF)
| ID | 요구사항 | 우선 |
|---|---|---|
| F-SF-01 | 입력: 아이템 레벨, 현재 성, 목표 성(최대 30), 파괴방지 적용 구간(15~17성 각각 켜고 끄기), 할인/이벤트 | P1 |
| F-SF-02 | 마르코프 체인으로 **메소 기댓값과 기대 파괴 횟수** 계산 | P1 |
| F-SF-03 | 몬테카를로(기본 10만 회)로 **중앙값, 75/90/95 백분위, 분포 히스토그램** | P1 |
| F-SF-04 | 파괴 처리: 직전 성 유지(22성 상한) 규칙에 따라 스페어 복구 비용(스페어 수 × 스페어 시세 + 복구 메소)을 포함하거나, 12성 복구 선택 | P1 |
| F-SF-05 | **구간별 최적 파괴방지 전략** 제안(파괴방지 on/off 조합 중 기댓값 최소) | P2 |
| F-SF-06 | 성별 스탯 상승량 표시(방어구/무기, 레벨별) | P2 |

#### 4.2.2 잠재능력 / 에디셔널 (F-POT)
| ID | 요구사항 | 우선 |
|---|---|---|
| F-POT-01 | 입력: 부위, 아이템 레벨, 현재 등급, 목표 등급, 목표 옵션(프리셋 또는 직접 조건) | P1 |
| F-POT-02 | 등급업 기댓값: 확률과 천장을 반영한 메소 기댓값과 백분위 | P1 |
| F-POT-03 | 목표 옵션 달성 확률(1회당)과 기대 시도 횟수, 메소 기댓값. 옵션 확률표는 데이터 파일 사용 | P1 |
| F-POT-04 | 프리셋: 주스탯 %(21/24/27/30/33/36+), 올스탯, 크뎀 1~2줄, 쿨감, 공/마 %(무기/보조/엠블렘), 보공·방무 조합, 에디 공/마 + 주스탯% 등 | P1 |
| F-POT-05 | 직접 조건: "옵션 A 합 ≥ x" AND/OR 조합 | P2 |
| F-POT-06 | 큐브(프라임/메모리얼 등 캐시·보스 재화) 경로를 선택적으로 비교 | P3 |

#### 4.2.3 추가옵션 (F-FLAME)
| ID | 요구사항 | 우선 |
|---|---|---|
| F-FLAME-01 | 메소 재설정(300만 고정, 검환불 확률)으로 목표 추옵 급수에 도달하는 확률과 기댓값 | P1 |
| F-FLAME-02 | 급수 환산식(주스탯 1, 부스탯 1/8~1/10, 공 ×4, 올스탯% ×10 등) 사용자 수정 가능 | P1 |
| F-FLAME-03 | 무기 공/마 추옵 티어 기준 목표 | P2 |

#### 4.2.4 직작 vs 구매 분석 (F-CMP)
| ID | 요구사항 | 우선 |
|---|---|---|
| F-CMP-01 | **손익분기 가격**: "완제품 시세가 X억 이상이면 직작이 이득"을 단계별(SF/잠재/에디/추옵)과 합계로 표시 | P1 |
| F-CMP-02 | 기댓값 기준 이득/손해 = 완제품 시세 − (베이스 구매가 + 직작 기댓값) | P1 |
| F-CMP-03 | 리스크 지표: 직작 비용이 시세를 넘을 확률(손해 확률), 90 백분위 기준 최악의 경우 | P1 |
| F-CMP-04 | **혼합 전략 비교**: 예를 들어 "17성 매물 구매 후 22성 직작" vs "22성 완제 구매" vs "노작 베이스에서 전부 직작" | P2 |
| F-CMP-05 | 이벤트 비교: 현재 조건 vs 이벤트 조건의 기댓값 차이("기다리면 N억 절약") | P2 |

### 4.3 시세 관리 (F-PRICE)

| ID | 요구사항 | 우선 |
|---|---|---|
| F-PRICE-01 | 매물 단위 수동 입력: 아이템, 부위, 성, 잠재(등급과 3줄), 에디(등급과 3줄), 추옵(급수/상세), 가위 잔여, 가격, 자서버/타서버, 관측 일시, 메모 | P1 |

| F-PRICE-03 | 타서버 매물의 실구매가 = 가격 + 가격 × 10%(메이플포인트를 원화와 메소로 환산) | P1 |

| F-PRICE-06 | 스페어(노작 베이스) 시세 등록. 스타포스 복구 비용 계산에 연동 | P1 |
| F-PRICE-07 | 오래된 시세 경고(N일 경과) | P2 |

## 5. 비기능 요구사항

| ID | 요구사항 |
|---|---|
| NF-01 | **설치와 실행 간소화**: Windows에서 `start.bat` 하나로 실행(최초 1회 의존성 설치 자동화) |
| NF-02 | **성능**: 스타포스 마르코프 계산은 100ms 미만, 몬테카를로 10만 회는 3초 미만 |
| NF-03 | **정확성**: 계산 엔진에 단위 테스트를 둠. 리서치의 검증 수치(예: 200제 12→18성 샤타포스 = 16.54억, 파괴 0.42회)를 회귀 테스트로 고정 |
| NF-04 | **유지보수성**: 확률, 비용, 옵션 수치는 코드가 아니라 `data/game/*.yaml`에 두고, 출처와 기준 패치를 명시 |
| NF-05 | **데이터 보존**: 시세 CSV와 설정은 로컬 `data/user/`에 저장. 앱 업데이트 시 덮어쓰지 않음 |
| NF-06 | **보안**: API 키는 로컬에만 보관하고 로그에 출력하지 않음. 서버는 localhost에만 바인딩 |
| NF-07 | **약관 준수**: 경매장 자동 수집 금지. 오픈 API 데이터는 30일 이내 갱신 정책 준수 |
| NF-09 | **오픈 API 정책 준수**: 화면에 "Data based on NEXON Open API" 출처를 표기. 키는 사용자 PC에만 저장하고 외부 서버로 전송하지 않음(키 양도·타인 키 사용 금지 조항, 리서치 07). 주기적 폴링 금지(수동 새로고침만) |
| NF-08 | **투명성**: 모든 결과에 계산 가정(확률표 버전, 할인, 이벤트)을 표시. 미검증 수치는 ⚠ 표시 |

## 7. 제약과 가정

- 게임 수치는 2026-10-15 조사 기준이며, 리서치 문서의 [미검증] 항목은 구현하면서 검증한다.
  - 대상: 스타포스 23~29성 비용 계수, 복구 메소 공식, MVP 할인 상한, 미라클 타임과 천장의 관계 등
- 환산 주스탯은 비공식 지표이므로, 이 도구의 값은 외부 사이트와 다를 수 있다.
- 메소마켓 시세와 아이템 시세는 사용자가 입력한 값만큼만 정확하다.

## 8. 수용 기준 (MVP)

1. Windows에서 `start.bat`을 실행하면 브라우저에 UI가 열린다.
2. 200제 방어구 12→22성(파괴방지 off, 할인 없음)의 기댓값과 백분위가 계산되고, 커뮤니티 계산기 값과 ±1% 안에서 일치한다.
